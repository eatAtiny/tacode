# 4. UI 系统

## 设计目标

支持可插拔的 UI 后端，同一套 Agent 逻辑适配不同使用场景。核心特点：

- **接口抽象**：所有 UI 操作通过 `UI` 接口，Agent 核心不感知具体实现
- **两种实现**：终端交互式（BubbleUI）和编程式（TextUI）
- **流式渲染**：LLM 响应逐 token 推送，用户实时可见
- **组件化**：BubbleUI 内部使用 Bubble Tea 组件拆分关注点

## UI 接口

```go
type UI interface {
    // 生命周期
    Init() error
    Close() error

    // 事件响应
    OnEvent(event QueryEvent)

    // 权限确认
    ConfirmPermission(toolName, reason string) (bool, error)

    // 用户输入
    ReadInput() (string, error)

    // 状态显示
    SetStatus(status StatusInfo)
}
```

## 两种实现

### BubbleUI — 终端交互式

`internal/ui/bubble/bubble.go`

- 基于 [lipgloss](https://github.com/charmbracelet/lipgloss) 的样式系统
- 基于 [glamour](https://github.com/charmbracelet/glamour) 的 Markdown 渲染
- ANSI 光标控制实现流式输出
- `bufio.Scanner` 读取输入（主循环不是 Bubble Tea）

组件架构：
```
BubbleUI
  ├── ConversationModel  — 可滚动的对话历史
  ├── InputModel         — 文本输入栏 + 历史导航
  ├── StatusModel        — 状态栏（会话名、模型、token 数）
  └── ToolViewModel      — 工具执行弹窗（展开/收起）
```

### TextUI — 编程式/无头

`internal/ui/text/text.go`

- 通过 `OnEvent` 回调分发事件
- 自动批准所有权限（`ConfirmPermission` 始终返回 true）
- 用于子 Agent 场景、自动化脚本、测试
- 无终端依赖，输出为纯文本

## 事件流

```
queryLoop → QueryEvent channel → UI.OnEvent()
                                    ├── Think          → 状态栏显示"思考中"
                                    ├── Delta          → 流式追加到当前消息
                                    ├── ToolCall       → ToolViewModel 展开
                                    ├── ToolResult     → ToolViewModel 更新结果
                                    ├── Permission     → 弹出确认提示，阻塞等待输入
                                    ├── Final          → 标记消息完成
                                    └── Error          → 错误显示
```

## Components

### ConversationModel

- 维护消息列表，支持上下滚动
- Markdown 渲染（代码块、列表、标题等）
- 自动跟踪最新消息（滚动到底部）

### InputModel

- 多行文本输入
- 历史记录导航（↑↓）
- 快捷键支持（Ctrl+C 取消，Enter 提交）

### StatusModel

- 左：当前会话名
- 中：模型名称
- 右：Token 使用量 / 预算

### ToolViewModel

- 工具调用时展开详情面板
- 显示工具名、参数、结果
- 执行中显示 spinner 动画
- 可折叠/展开

## 选择逻辑

```go
// main.go
if isTTY {
    ui = bubble.NewBubbleUI()
} else {
    ui = text.NewTextUI()
}
```

- `isTTY`：检测 stdin 是否为终端
- BubbleUI 用于直接交互
- TextUI 用于管道、重定向、自动化
