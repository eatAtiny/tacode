# 项目简历介绍 — Tacode（Go ReAct Agent）

> 面向求职/评审的简历素材。完全对照给定模板的「项目简介 / 技术栈 / 核心实现」三段式结构，内容基于本项目源码与架构梳理，可直接用于简历或面试准备。

## 项目简介

基于 Go 构建的 AI 智能体平台（类 Claude Code 的终端 AI Agent），集成了多模型 AI 对话、ReAct 智能任务执行、长上下文自动压缩、三层记忆管理、多会话管理等核心功能。项目采用异步事件驱动 + 分层模块化架构，为企业和开发者提供一站式的 AI 智能体解决方案。

## 技术栈

Go 1.26 + OpenAI 流式接口 + Bubble Tea（终端 UI）+ MCP + JSONL 持久化 + 沙箱隔离

## 核心实现

1. **ReAct 智能体引擎与异步事件驱动架构**：采用两层查询架构（QueryEngine 协调层 + queryLoop 核心循环）+ 异步生成器模式（`<-chan QueryEvent` 事件流）解决 Agent 自主决策与多轮工具调用编排的耦合问题，实现核心循环与 UI/事件日志彻底解耦、任意 UI 可插拔、核心循环可独立单测。

2. **多模型 AI 集成与流式对话架构**：基于 go-openai 深度集成主流大模型（OpenAI / DeepSeek / 豆包 / 腾讯混元，经自定义 BASE_URL 与模型名适配），设计统一的多模型适配层解决不同 AI 服务商 API 协议差异，统一流式响应处理机制，采用 channel 流式传输实现增量文本实时渲染，避免阻塞式等待带来的性能损耗，附带 token 用量统计、429/5xx 重试与账户余额查询。

3. **长上下文管理与无损压缩管线**：设计 5 步上下文压缩管线（4 步无损落盘 + 1 步 LLM 摘要）解决长对话上下文无限增长导致的 token 超限、`prompt_too_long` 报错与 API 400 问题，通过大结果转存、消息归档、微压缩、配对保护等机制在 50K 字符预算内无损保住对话信息，并实现响应式压缩作为 API 拒绝时的兜底补救。

4. **三层记忆系统与 LLM 自动提取**：设计 L1 原始日志 / L2 摘要 / L3 结构化长期记忆三层存储，L3 按全局 / 项目 / 会话三档路由，由 LLM 每轮自动提取记忆动作（create / update / delete），解决跨会话、跨项目的长期记忆持久化与检索问题，实现「记住用户偏好与项目上下文」的持续学习能力。

5. **MCP 协议集成与工具调用生态**：集成 Model Context Protocol，实现 AI 智能体与外部工具的标准化交互（stdio 客户端连接外部 MCP server），采用适配器模式将 MCP 工具统一转换为 `tool.Tool` 接口，解决工具调用的动态加载与热插拔问题；内置 8 个工具（shell / file / edit / grep / list / git / webfetch / compact），10 方法工具接口支持一键扩展。

6. **工具权限与并发安全调度**：采用两级权限体系（工具自检 `CheckPermission` + 全局权限注入点 + 禁止名单）+ 并发安全分类调度解决高危工具误操作与并行执行上下文一致性问题，只读工具用 goroutine 并行执行、结果按原始顺序回灌保证 LLM 上下文一致性，read-before-edit 通过 mtime 检测防止「未读就改 / 外部篡改」。

7. **多会话管理与懒持久化**：设计会话独立目录 + manifest 索引 + 临时会话懒持久化机制，解决多会话隔离、空会话污染、崩溃残留目录清理问题，交互式会话选择器提升切换效率。

8. **沙箱隔离与 Agent 安全**：实现网络 / 文件系统隔离的沙箱抽象（Linux 命名空间 / macOS seatbelt 临时 profile），解决 Agent 执行 shell 命令时的环境隔离与资源限制问题，配合危险命令检测构建纵深防御。

## 核心实现（精简简历版）

> 与上方详细版同源，仅改写表述：删除 QueryEngine / queryLoop / `tool.Tool` / `CheckPermission` 等项目内命名，改用通用专业术语，长度约减半，可直接用于简历正文或面试口头介绍。

1. **智能体引擎与异步事件驱动**：采用「编排层 + 核心执行循环」两层架构，核心循环以异步生成器对外产出事件流，将决策逻辑与界面渲染、事件日志彻底解耦 —— 任意 UI 可插拔接入，核心逻辑可脱离 UI 独立测试。

2. **长上下文无损压缩管线**：五步压缩管线（四步无损落盘 + 一步大模型摘要），以超大结果转存、历史消息归档、上下文微压缩与「调用-响应」消息配对保护等手段，在有限上下文预算内无损保留对话，规避长度超限与接口格式错误；请求被拒时以响应式压缩兜底并自动重试。

3. **三层记忆与自动提炼**：原始对话日志 / 会话摘要 / 结构化长期记忆三层存储，长期记忆按全局、项目、会话三种作用域路由；大模型每轮自动提炼「增 / 改 / 删」记忆动作，实现跨会话、跨项目的用户偏好与项目上下文沉淀。

4. **MCP 与可扩展工具生态**：以适配器模式将外部 MCP 工具统一映射为内部工具接口，支持工具动态加载与即插即用；内置命令执行、文件读写编辑、结构化检索、版本控制、网页抓取、上下文管理等基础能力，统一的多方法工具接口便于新增工具一键接入。

5. **分级权限与并发安全调度**：两层权限模型（工具自检 + 全局可注入策略）拦截高风险操作；只读任务并发执行、结果按原始顺序回填，保证模型上下文一致；「先读后改」的编辑流程配合文件变更检测（时间戳比对），防止未读先改与外部篡改。

6. **多会话与惰性持久化**：会话独立目录 + 索引清单实现上下文隔离；临时会话惰性落盘，避免空会话污染数据目录，并自动清理异常残留；交互式会话切换器提升多任务效率。

7. **沙箱隔离与纵深防御**：基于操作系统级隔离（Linux 命名空间 / macOS seatbelt）限制 Agent 命令的网络与文件访问，叠加资源配额与危险命令检测，构成纵深防御，保障执行安全。
